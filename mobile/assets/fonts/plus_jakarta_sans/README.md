# Plus Jakarta Sans

Unmodified variable TrueType fonts from Google Fonts, authored by the Plus Jakarta
Sans Project Authors (Tokotype). Upright and italic files support the weight axis;
pubspec maps the design-system weights 400/500/600/700 to these local assets.
There is no runtime download or font package dependency.
